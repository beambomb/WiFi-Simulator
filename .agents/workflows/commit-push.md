description: Review changes, enforce max 3 files per commit, and push to origin main
---

Please execute a clean git commit and push workflow:
1. Run `git status` to inspect all staged, unstaged, and untracked changes.
2. Group changed files into logical batches of **maximum 3 files per commit**.
3. Create clear and descriptive conventional commit messages (e.g., `feat:`, `fix:`, `docs:`, `style:`).
4. Run `git push origin main` to synchronize commits with the remote GitHub repository.
5. Report the commit hashes and status to the user.
